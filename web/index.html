What is BCIO?

An AI agent terminal that reads stock tokens (NVDA, TSLA, QQQ) and crypto (BTC, ETH, SOL, AI coins) together. It finds correlations and lags, then builds a basket you can approve with one signature.

Does the agent hold my funds?

No. You sign every basket in your own wallet. Automations (Weekend Shield, rebalancer) only run inside limits you set on-chain: max per trade, max per day and an expiry. You can revoke the agent at any time.

Are stock tokens the same as shares?

No. Stock tokens are tokenized exposure on Robinhood Chain, not shares. On the current testnet the terminal trades test tokens priced from live market data.

Which network does it run on?

Robinhood Chain testnet (chain id 46630). No real money is involved yet.

Is this financial advice?

No. The agent shows data and builds suggestions. The numbers on this page are demo data, and correlations describe the past, not the future.
